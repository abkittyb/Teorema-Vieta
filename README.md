# Теорема Виета

Учебный тренажёр для устного подбора целых корней квадратных уравнений. Автор проекта — [@abkittyb](https://github.com/abkittyb).

В репозитории находится настольный прототип на Python и Tkinter. Цель проекта — перенести тренажёр на Android.

## Как запустить

Понадобится Python 3 с Tkinter. Чтобы проверить наличие Tkinter, выполните `python -m tkinter` — должно открыться тестовое окно.

Скачайте репозиторий через **Code → Download ZIP**, распакуйте архив и запустите из его папки:

```sh
python TR.Vieta.py
```

Если на вашем компьютере Python 3 запускается командой `python3`, используйте её в обеих командах.

## Как проходит тренировка

1. Нажмите **Старт** и подберите два целых корня. Например, для уравнения x² − 5x + 6 = 0 сумма корней равна 5, а произведение равно 6. Подходят 2 и 3.
2. Введите корни в любом порядке и нажмите **Проверить**. При ошибке тренажёр покажет правильные корни.
3. Перейдите к следующему уравнению или нажмите **Завершить**, чтобы увидеть время, число попыток, ошибки и итоговую оценку.

Генератор предлагает приведённые и неприведённые уравнения, а также задания с нулевым корнем или противоположными корнями.
